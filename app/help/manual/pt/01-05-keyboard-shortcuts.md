# Atalhos de teclado

| Tecla | O que faz |
|---|---|
| `Alt+C`, `Alt+A`, `Alt+V`, `Alt+M`, `Alt+H` | abrem os menus Catálogo, Aplicações, Ver, Monitorização e Ajuda (o primeiro menu cujo nome em inglês começa pela letra: `Alt+A` é Aplicações) |
| `/` | vai para Ferramentas e põe o cursor no filtro |
| `R` | atualiza tudo a partir do serviço (como Catálogo › Atualizar) |
| `Esc` | fecha o painel, um menu ou o menu Definições |
| `Enter` num formulário | o botão principal do formulário |

Os atalhos funcionam quando o cursor não está num campo de texto.
