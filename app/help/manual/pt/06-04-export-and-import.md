# Exportar e importar o registo

O **registo** é o catálogo de ferramentas e competências. Exporte-o para guardar uma cópia ou para levar uma ferramenta
para outra instalação; importe uma cópia com um ensaio primeiro.

## Exportar

- **Catálogo** › **Exportar o registo** (ou Definições › **Registo em JSON**): tudo, em JSON.
- Filtre as **Ferramentas** por uma aplicação, depois **Catálogo** › **Exportar a aplicação <app>**: a fatia dessa
  aplicação.

## Importar (ensaio)

1. **Catálogo** › **Importar (ensaio)…**, ou Definições › **Importar (ensaio)**, e escolha o ficheiro JSON.
2. A página lista o que o ficheiro iria **criar** e o que iria **atualizar**, com a diferença de cada atualização.
   Nada é alterado ainda.
3. Clique em **Aplicar n alteração(ões)** para as guardar, cada uma como uma nova versão.

## Notas

- As chaves e a atividade não fazem parte do registo.
- Os nomes são a identidade: um registo do ficheiro com um nome já existente atualiza-o.
