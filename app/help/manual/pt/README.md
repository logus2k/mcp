# Manual do utilizador do MCP Server

O MCP Server é o **anfitrião partilhado de ferramentas e competências** do domínio. As aplicações e os agentes ligam-se
a ele para usar **ferramentas** (pesquisa na web, leitura de URLs, notícias, os sensores do SDLC, o registo no proxy) e
**competências** (instruções que vários deles têm de aplicar da mesma forma). Administra-o na **Consola MCP**: o que é
oferecido a que aplicação, quem o pode chamar, o que foi chamado e por quem.

Cada página abaixo é uma tarefa, passo a passo.
