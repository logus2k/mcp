# Restore an earlier version

Every save adds a version to a tool's (or a skill's) **History**. Restoring makes an earlier version current again, as
a new version: nothing is ever lost.

## Steps

1. Open the tool and click **History**. The versions are listed, newest first, with the date, the action and who
   did it; the two newest are compared below the list.
2. Click **Restore** beside the version you want.
3. The tool reopens on the restored content, saved as the newest version.

## Notes

- A record created before the history log started has no versions until its next change.
- Restoring a deleted tool: its history is kept; create it again with the same name and restore from there.
