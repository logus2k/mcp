# MCP Server User Manual

MCP Server is the shared **tool and skill host** of the domain. Applications and agents connect to it to use
**tools** (web search, URL fetch, news, the SDLC sensors, the proxy registration) and **skills** (instructions several
of them must apply the same way). You administer it in the **MCP Console**: what is offered to which app, who may call
it, what was called, and by whom.

Each page below is one task, step by step.
