# See a tool's calls

Every call of a tool is recorded: when, for which app, by which caller, on whose behalf, how long it took, and whether
it succeeded.

## Steps

1. Open the tool and click **Activity**: the last 50 calls of the last 30 days.
2. Hover an *error* pill to read the error the caller received.
3. For more, click **Activity** in the side menu and filter by the tool's name in the search field.

## Notes

- The **Overview** tab sums it up: calls and errors in the last 24 hours, and when the tool was last used.
- A tool executed by the app's own page has no calls here: the service never runs it.
