# Keyboard shortcuts

| Key | What it does |
|---|---|
| `Alt+C`, `Alt+A`, `Alt+V`, `Alt+M`, `Alt+H` | open the Catalog, Apps, View, Monitoring and Help menus (the first menu whose name starts with the letter: `Alt+A` is Apps) |
| `/` | goes to Tools and puts the cursor in its filter |
| `R` | refreshes everything from the service (as Catalog › Refresh) |
| `Esc` | closes the drawer, a menu, or the Settings menu |
| `Enter` in a form | the form's main button |

The shortcuts work when the cursor is not in a text field.
