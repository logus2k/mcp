# Try a skill

**Try it** renders a skill exactly as a client receives it from `prompts/get`, with the arguments you fill in.

## Steps

1. Open the skill (select its row in **Skills**) and click **Try it**.
2. Fill the arguments, or leave them: an argument with a default takes it, an optional one without a default stays
   as written (`{{name}}`).
3. Click **Render as prompts/get**. The text appears below.

## Notes

- **Content** shows the skill as stored, placeholders unresolved: what `resources/read` returns.
- **Connect** shows how a client asks for it.
